Interface non compilée

Le serveur local tourne, mais le bundle de l'interface (apps/web/dist) est introuvable. Compilez-le puis relancez l'application :

npm run build -w @draftpredict/web

En développement, lancez plutôt npm run dev -w @draftpredict/web et démarrez la coquille avec DRAFTPREDICT_DEV=1.
